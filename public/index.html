    界面启动 / 复核方式

    1. npm start 后浏览器打开 http://localhost:3000（无需联网、无运行时依赖）。
    2. 命令行复核：npm test（28 项：DSP 参照 / OLA 流式 / 真实 Worklet 源码 / jsdom 界面接线；首次先 npm install 安装 jsdom）或 npm run verify（生成 output/*.wav 与报告）。
    3. 真实浏览器端到端（可选）：npm i -D playwright && npx playwright install chromium 后，先 npm start，再 npm run smoke:browser（31 项交互/下载/参数往返/零控制台错误）。
    4. 无浏览器 JSON 复核：/api/verify、/api/demo/measurements、/api/demo/session.wav?path=echo|iem。
